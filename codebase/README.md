- **Mục đích:** Chứa mã nguồn của prototype Bot Discord Trợ lý Logistics (hoặc Web Interface mô phỏng).
- **Mức prototype:** Working prototype (có gọi API LLM thực tế để phân loại intent và kiểm tra grounding).
- **Phân định rõ:**

  - Phần mock: Giao diện giả lập hoặc dữ liệu thông báo giả định.
