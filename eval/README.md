# Thư mục Đánh giá & Kiểm thử (Evaluation)

- **Mục đích:** Lưu trữ bộ Golden Set (≥20 cases) và bảng kết quả đo lường độ chính xác (Precision, Fallback Rate, Zero-Hallucination Rate).
- **Files chính:**
  - `golden_set_b1.json`: 20 test cases theo 4 nhóm kịch bản (Happy path, Thiếu dữ liệu, Mâu thuẫn thông báo, Injection).
  - `results.md`: Bảng ghi nhận kết quả các lượt chạy kiểm thử qua từng phiên bản prompt.
